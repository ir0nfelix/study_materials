# Skill: Удаление задачи (`/rm`)

## Триггер
Пользователь пишет: `/rm задача 44` или `/rm #task-044...`

## Рабочий процесс

1. **Определение задачи**
   - Найди номер задачи или `{#slug}` в сообщении пользователя.
   - С помощью `grep_search` найди файл (например `docs/livecoding/python.md`) и строку начала карточки (например `## Задача 44:` или атрибут `{#slug}`).

2. **Просмотр границ**
   - Используй `view_file` для чтения содержимого файла вокруг найденной строки.
   - Определи границы удаляемого блока (от найденного заголовка `## Задача N:` до строки перед следующим заголовком `## Задача N+1:` или конца файла).

3. **Подтверждение**
   - Спроси пользователя: "Вы уверены, что хотите удалить задачу **<Название>** из файла `<имя_файла>`?"
   - ДОЖДИСЬ ответа пользователя.

4. **Удаление**
   - Используй инструмент `replace_file_content` или `multi_replace_file_content` для удаления найденного текстового блока целиком (замени на пустую строку `""`).
   - Сообщи пользователю об успешном удалении.

## Важно
- **Не используй bash-скрипты** (`sed`, `awk`) для редактирования `.md` файлов. Используй только нативные инструменты агента.
- Убедись, что не удаляешь лишние пустые строки перед следующей задачей.
