# Skill: Редактирование задачи (`/edit`)

## Триггер
Пользователь пишет: `/edit задача 44` или `/edit #task-044...`  
Опционально — с описанием что хочет поменять: `/edit задача 44 — поправь условие`

## Рабочий процесс

### Шаг 1: Найти задачу

1. Извлеки номер задачи или `{#slug}` из сообщения пользователя.
2. Используй `grep_search` для поиска по всем `.md` файлам в `docs/`:
   - Ищи `## Задача N:` или `{#slug}`
   - Определи, в каком файле находится задача

### Шаг 2: Прочитать карточку

1. Используй `view_file` чтобы прочитать весь блок задачи — от найденного `## Задача N:` до строки перед следующим `## Задача N+1:` (или конца файла).
2. Покажи пользователю содержимое карточки **полностью**:
   ```
   📋 Задача N: <Название>
   Файл: docs/livecoding/python.md

   [полное содержимое карточки]
   ```

### Шаг 3: Выяснить что редактировать

Если пользователь уже написал что хочет поменять — используй это. Иначе спроси:  
*«Что вы хотите изменить в этой карточке? Например: условие задачи, эталонное решение, заголовок.»*

**Распространённые сценарии:**
- **Условие** → редактируй секцию `### Условие`
- **Эталонное решение** → редактируй секцию `### Эталонное решение (AI)`
- **Перегенерировать решение через LLM** → прими это как флаг `regenerate: true` (см. ниже)
- **Заголовок** → редактируй строку `## Задача N: ...`, сохраняя `{#slug}` атрибут

### Шаг 4: Внести правку

**Вариант A — прямое редактирование** (пользователь диктует текст):
1. Прими от пользователя новый текст нужной секции.
2. Используй `replace_file_content` для точечной замены целевого блока.
3. Строго соблюдай правила разметки из `.agents/AGENTS.md`, раздел 3:
   - Внутри карточки **нельзя** использовать `#` и `##`
   - Не удалять `{#slug}` из заголовка H2

**Вариант B — перегенерация через LLM** (если пользователь хочет новое решение):
1. Спроси: *«Хотите перегенерировать решение через Эксперта? (использует `anthropic/claude-sonnet-4`)»*
2. Если да — прочитай JSON из `.cache/99_completed/` (или создай временный JSON с условием задачи),
   запусти Эксперта:
   ```bash
   ./venv/bin/python agents/03_expert/solve.py <path_to_json>
   ```
3. Прочитай `expert_solution` из обновлённого JSON и замени секцию `### Эталонное решение (AI)` в `.md` файле.

### Шаг 5: Подтверждение

После внесения правок:
1. Покажи изменённую карточку (или diff — что было vs. что стало).
2. Сообщи: «Задача N обновлена в `<файл>`. MkDocs подтянет изменения автоматически.»

## Критические правила

- 🚫 **НЕ трогай** соседние задачи при редактировании.
- 🚫 **НЕ удаляй** `{#slug}` атрибут из строки заголовка `## Задача N:`.
- 🚫 **НЕ используй** bash-скрипты (`sed`, `awk`) для редактирования `.md` файлов.
- ✅ Используй только `replace_file_content` или `multi_replace_file_content`.
- ✅ Перед правкой всегда читай весь блок задачи целиком (`view_file`).
- ✅ После правки проверь, что соседние задачи не пострадали.
