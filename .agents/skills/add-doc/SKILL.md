# Skill: Добавление задач из документов (`/add doc`)

## Триггер
Пользователь пишет в чат: `/add doc <путь_к_файлу>`

## Инструменты
- `agents/01_ingestion/ingest_doc.py <path>` — извлекает текст из PDF/текстового файла и складывает в `raw_transcripts/`
- `agents/02_miner/mine.py <path_to_txt>` — извлекает задачи с помощью LLM

## Рабочий процесс

1. **Обработка документа**
   - Если файл — это изображение (PNG, JPG), используй свои встроенные multimodal возможности для OCR. Извлеки весь текст самостоятельно и сохрани его в `raw_transcripts/<имя_файла>.txt`.
   - Если файл — это PDF или текстовый документ, запусти скрипт парсинга:
     ```bash
     ./venv/bin/python agents/01_ingestion/ingest_doc.py <путь_к_файлу>
     ```
     Скрипт создаст текстовый файл в директории `raw_transcripts/`.

2. **Извлечение задач (Miner)**
   - Запусти Miner для полученного текстового файла (путь к нему будет выведен скриптом на шаге 1, либо это файл, который ты создал для OCR изображения):
     ```bash
     ./venv/bin/python agents/02_miner/mine.py raw_transcripts/<имя_файла>.txt
     ```
   - Задачи появятся в `.cache/01_pending_triage/`.

3. **Сортировка (Triage)**
   - Сообщи пользователю: "Документ обработан. Найдено задач: X."
   - Перейди к скиллу `review-tasks` для интерактивного апрува (шаг с OCR там можно пропустить, так как код уже должен быть извлечен из документа).
