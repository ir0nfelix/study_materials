## Задача 10: HashMap в Java {#task-010-java-collection-hashmap}
**Источник:** [Java-собес： менти не дотянул до Middle. Почему нельзя говорить лишнего на собеседовании？](https://www.youtube.com/watch?v=IoXoGi41VtY)

### Условие
Объясните, как устроен HashMap в Java и какова его алгоритмическая сложность.
### Решение кандидата
HashMap - это класс, который реализует интерфейс Map и хранит данные в формате ключ-значение. Он использует хеш-функцию для определения, в какой ячейке будет храниться объект. Если происходит коллизия, используется метод цепочек для хранения нескольких объектов в одной ячейке. Алгоритмическая сложность поиска элемента в лучшем случае O(1), но в худшем случае может достигать O(n).
### Эталонное решение (AI)
HashMap в Java хранит данные в виде пар ключ-значение и использует хеш-функцию для определения индекса хранения. При коллизиях используется связный список или дерево. В среднем, сложность поиска составляет O(1), но в случае коллизий может увеличиться до O(n) в худшем случае.

## Задача 13: Проблема N+1 {#task-013-java-database-n-plus-one-problem}
**Источник:** [Java： ПЕРВОЕ собеседование в жизни. ТехЛид МТС поставил мне грейд Стажёр.](https://www.youtube.com/watch?v=LI4cpOk5eGs)

### Условие
Что такое проблема N+1 и как её можно решить?
### Решение кандидата
Кандидат объясняет, что проблема N+1 возникает, когда для получения связанных данных выполняется слишком много запросов к базе данных. Например, сначала загружается список объектов, а затем для каждого объекта выполняется отдельный запрос для получения связанных данных. Решение включает использование жадной загрузки (eager loading) или написание более сложных запросов.
### Эталонное решение (AI)
Проблема N+1 возникает, когда для получения связанных данных выполняется один запрос для основного объекта и N запросов для связанных объектов. Решения включают использование JOIN в SQL-запросах, использование аннотаций @EntityGraph в JPA или использование библиотеки Hibernate с жадной загрузкой.
