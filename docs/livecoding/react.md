

## Задача 1: Таймер с запросом {#task-001-react-timer-request}
**Источник:** [Реальное собеседование на Middle⧸Senior Frontend-разработчика со сложными вопросами! Собес с ЗП 300К](https://www.youtube.com/watch?v=ijprxQH2tMo)

### Условие
При нажатии на кнопочку стартуем таймер. Когда таймер достигает нуля, кнопку необходимо убрать и отправить запрос на определённый endpoint.
### Решение кандидата
Кандидат предложил использовать стейт для таймера, инициализировав его значением 5. Также он упомянул, что нужно использовать эффект для обработки таймеров и сайд-эффектов. В процессе обсуждения были предложены дополнительные условия, такие как отображение загрузчика во время выполнения запроса.
### Эталонное решение (AI)
Для реализации задачи можно использовать React hooks, такие как useState для хранения состояния таймера и useEffect для управления таймером. При каждом обновлении состояния таймера можно использовать setTimeout для уменьшения значения таймера. Когда таймер достигает нуля, можно скрыть кнопку и отправить запрос с помощью fetch или axios.

## Задача 2: Обработка данных и отображение {#task-002-react-data-processing-display}
**Источник:** [Реальное собеседование с интересным лайвкодингом на Middle⧸Senior Frontend-разработчика на ЗП 320К!](https://www.youtube.com/watch?v=k9HE34qB9pQ)

### Условие
Необходимо вернуть массив с ID, у которых статус 'complete', отсортированных по убыванию суммы заказа. Данные приходят в виде массива объектов с полями 'customer ID', 'status' и 'amount'.
### Решение кандидата
Кандидат предложил создать объект типа 'map', где ключом будет 'customer ID', а значением - общая сумма заказов для этого ID. Затем он планирует отсортировать массив по убыванию суммы и вернуть нужные элементы.
### Эталонное решение (AI)
1. Создать объект для хранения сумм заказов по 'customer ID'.
2. Пройтись по массиву данных и для каждого элемента проверить статус. Если статус 'complete', добавить сумму к соответствующему 'customer ID' в объекте.
3. Преобразовать объект в массив и отсортировать его по убыванию суммы.
4. Вернуть массив ID, соответствующих отсортированным суммам.

## Задача 3: Рекурсивный обход дерева {#task-003-react-algorithm-tree-traversal}
**Источник:** [Реальное собеседование с интересным лайвкодингом на Middle⧸Senior Frontend-разработчика на ЗП 320К!](https://www.youtube.com/watch?v=k9HE34qB9pQ)

### Условие
Необходимо обойти дерево и преобразовать его в массив, используя рекурсию. Дерево может содержать вложенные структуры.
### Решение кандидата
Кандидат предложил использовать рекурсию для обхода дерева, проверяя каждый элемент. Если элемент примитивный, он добавляется в результат, если массив, то рекурсивно обрабатывается каждый элемент массива.
### Эталонное решение (AI)
1. Создать функцию, которая принимает узел дерева.
2. Проверить тип узла: если это массив, пройтись по каждому элементу и вызвать функцию рекурсивно.
3. Если узел примитивный, добавить его в результирующий массив.
4. Вернуть результирующий массив после обхода всех узлов.

## Задача 4: Реализация useDebounce {#task-004-react-hook-debounce}
**Источник:** [Реальное собеседование с интересным лайвкодингом на Middle⧸Senior Frontend-разработчика на ЗП 320К!](https://www.youtube.com/watch?v=k9HE34qB9pQ)

### Условие
Необходимо реализовать свой хук useDebounce, который будет задерживать выполнение функции до тех пор, пока не пройдет заданный интервал времени.
### Решение кандидата
Кандидат описал, что хук должен принимать строку для поиска и задержку. Он предложил использовать setTimeout для создания задержки перед вызовом функции поиска.
### Эталонное решение (AI)
1. Создать хук useDebounce, который принимает значение и задержку.
2. Использовать useEffect для установки таймера с помощью setTimeout.
3. Когда значение изменяется, очищать предыдущий таймер и устанавливать новый.
4. Возвращать значение, которое будет обновляться только после истечения задержки.

## Задача 5: Таймер с запросом {#task-005-react-timer-request}
**Источник:** [Реальное собеседование на Middle⧸Senior Frontend-разработчика со сложными вопросами! Собес с ЗП 300К](https://www.youtube.com/watch?v=ijprxQH2tMo)

### Условие
Когда вы нажимаете кнопку, таймер запускается. Когда таймер достигает нуля, кнопка удаляется. Также необходимо отправить запрос по истечении времени.
### Решение кандидата
Кандидат предложил использовать состояние для таймера, инициализировав его значением 5. При достижении нуля кнопка скрывается, и отправляется запрос.
### Эталонное решение (AI)
Для реализации задачи можно использовать хук useState для хранения значения таймера и useEffect для управления таймером и отправкой запроса по истечении времени.
